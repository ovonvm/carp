# 11. 播放、预览与文本编辑

在文件页双击（或点行末「播放 / 预览」）时，Carp 按文件类型决定打开方式：

| 类型 | 行为 |
|---|---|
| 文件夹 | 进入该文件夹 |
| 音频 | **默认只打开右上角音频小窗**并播放（见 11.2）；完整播放器由小窗「>」打开 |
| 视频 | 打开全站播放浮层（见 11.3） |
| 图片 | 打开图片查看器（原图显示），可下载 |
| PDF | 内嵌浏览，可下载 |
| 文本类（txt/md/json/csv/代码等） | 只读查看，超过 1 MiB 的部分不显示，可下载完整文件 |
| 其它 | 提示下载后用本地程序打开 |

> 组空间里的文件目前只能「预览」：图片/文本/PDF 可看，音视频会提示下载后播放。

## 11.1 全站播放浮层

播放器不是单独页面，而是覆盖在界面上的一层，**切换页面不会打断播放**——你可以在听歌的同时去看下载、整理文件。

音频默认走右上角小窗（见 11.2）；小窗点「>」才展开完整播放器。视频直接打开浮层。

| 按钮 | 作用 |
|---|---|
| 收起 / 最小化 | 音频：隐藏浮层但**继续播放**，右上角出现音频小窗；视频：**暂停**并收起到顶栏小图标（进度保留） |
| 关闭并停止 | 完全结束播放并清空播放状态；视频关闭前会先记住进度 |
| 点浮层外部 | 音频：只收起，不停止；视频：**不关闭**（避免误触） |
| Esc | 与「收起 / 最小化」相同 |
| 顶栏图标 | 音频/视频最小化后，点顶栏对应图标重新展开；视频从暂停处继续 |
| 音频小窗 | 固定在右上角，可暂停/继续、拖进度、调音量、切歌、打开列表或展开完整播放器；点小窗外部或 × 只收起，不停止播放 |

音频与视频共用同一个浮层；登录账号退出时会自动停止播放，避免下一个人听到你的内容。

## 11.2 音频播放器

| 功能 | 说明 |
|---|---|
| 封面 | 同目录的 `<曲名>.jpg/png` 或 `cover.jpg/png`、`folder.jpg/png`；没有时显示占位图 |
| 实时频谱 | 随音乐跳动的频谱条；系统开启「减少动态效果」时保持静态 |
| 进度与跳转 | 拖动进度条；点歌词行跳到对应时间 |
| 音量 / 静音 | 滑块与静音按钮 |
| 倍速 | 0.5x、0.75x、1x、1.25x、1.5x、2x |
| 播放模式 | 默认「顺序播放」（列表播完即停，单曲同样）；按钮循环 顺序 → 列表循环 → 单曲循环 → 随机 |
| 歌词 | 同目录 `<曲名>.lrc`；自动高亮当前行并滚动 |
| 记忆续播 | 播放超过 10 秒后自动记住位置，下次打开同一首歌自动恢复；续播位置只保存在本机浏览器 |
| 播放列表 | 当前文件夹内同类型的音频，可按列表切换；音频小窗下方也能展开列表，每页 8 首可翻页 |

## 11.3 视频播放器

| 功能 | 说明 |
|---|---|
| 播放控制 | 播放/暂停、进度（含缓冲进度）、音量、倍速（0.5x–2x）、字幕开关、全屏 |
| 自动隐藏 | 控制条 3 秒无操作后隐藏，移动鼠标或点画面重新出现 |
| 字幕 | 自动加载同名字幕并渲染为原生字幕轨，可开关 |
| 信息条 | 显示标题、大小、修改时间，可「在文件夹中显示」或下载 |
| 播放列表 | 当前文件夹内同类型的视频 |
| 最小化 | 暂停后收起到顶栏小图标；再点图标回到浮层并从原位置继续 |
| 记忆续播 | 播放超过 10 秒后记住位置；最小化、关闭或下次打开同一视频自动恢复（只保存在本机浏览器） |
| 解码失败 | 浏览器不支持该格式时显示错误与「下载文件」按钮 |

## 11.4 侧车文件命名约定

播放器会在**同一文件夹**里按文件名找配套文件（「侧车」）：

| 用途 | 命名 |
|---|---|
| 封面 | `<文件名去扩展名>.jpg` / `.jpeg` / `.png`，或 `cover.*`、`folder.*` |
| 歌词 | `<文件名去扩展名>.lrc` |
| 字幕 | `<文件名去扩展名>.vtt` / `.srt` / `.ass` / `.ssa`（同时存在时优先 `.vtt`） |

## 11.5 字幕格式与限制

- `.vtt`：浏览器原生支持，直接加载。
- `.srt` / `.ass` / `.ssa`：在浏览器内即时转换为 WebVTT 后加载；ASS 的样式与特效会丢失，仅保留文字（界面会给出提示）。
- 超过 1 MiB 的字幕文件会被跳过。
- 不支持 MKV 内嵌字幕、图形字幕（PGS）与服务端转码。

## 11.6 能不能播放取决于浏览器

Carp 不做转码，也不内置 ffmpeg：文件原样交给浏览器解码。常见浏览器能直接播 MP4（H.264/AAC）、WebM、MP3、WAV、OGG、FLAC 等；**MKV、HEVC、部分 AVI、DTS 音轨通常无法播放**，表现为黑屏、无声音或提示下载。

## 11.7 文本预览说明

Carp 目前只提供文本**只读查看**，不提供在线保存编辑；需要修改请下载后用本地编辑器。查看只读取文件开头 1 MiB，超大文件请下载。
