# 9. 导航与界面

登录后的所有功能都通过一个网页界面完成，不需要另装客户端。

## 9.1 顶部栏

| 元素 | 位置 | 作用 |
|---|---|---|
| 站点标志 | 左 | 点击回到「我的文件」根目录 |
| 搜索框 | 中 | 按文件名搜索；回车进入搜索结果页（见 10.6） |
| 音频图标 | 右 | 仅在播放（或暂停）音频、且小窗被收起时出现：点击重新展开音频小窗 |
| 账户菜单 | 右 | 「设置」（修改密码、注销账号）与「登出」 |

## 9.2 左侧栏

左侧栏按登录身份显示不同入口，当前页面会高亮。

**所有用户**

| 入口 | 页面 | 说明 |
|---|---|---|
| 我的文件 | `/files` | 个人根目录；文件、文件夹都在这里 |
| 组空间 | `/groups/<id>` | 你加入的每个组显示为一条，组后带「管理员」标记表示你是组长 |
| 分享 | `/shares` | 你创建的分享链接列表 |
| 回收站 | `/trash` | 已删除的文件；有内容时显示数量角标 |
| 设置 | `/settings` | 修改密码、注销账号 |

> 「下载」与「离线下载」不再占用侧栏：在文件页工具条点「下载」或「离线下载」进入对应页面（页面对所有人都可用）。

**管理员额外显示**

| 入口 | 页面 | 说明 |
|---|---|---|
| 用户管理 | `/admin/users` | 创建、禁用、重置密码、永久删除账号 |
| 组管理 | `/admin/groups` | 建组、维护成员与组员权限（被委派建组权限的用户只看到「我的组」） |
| 审计日志 | `/admin/audit` | 按操作者 / 动作 / 时间查询 |
| 系统设置 | `/admin/settings` | 站点名称、注册开关、默认配额等 |
| 存储 | `/admin/storage` | 多本地存储根的查看与维护 |

侧栏底部显示存储用量条：只有账号设置了配额时才出现，格式是「已用 / 配额」。

## 9.3 文件页的结构

文件页从上到下依次是：

1. **面包屑**：显示当前位置，点击任意一级可跳回；根目录显示为「我的文件」。
2. **工具条**：新建文件夹、上传文件、上传文件夹、下载、离线下载，以及右侧的「列表 / 网格」切换。
3. **文件区**：默认网格（适合看缩略图与封面），可切列表（适合看大小与时间）。单击选中、双击打开；`Ctrl` 单击加选、`Shift` 单击区间选择；按住拖动可把项目移动到目录或面包屑。
4. **批量条**：勾选任意文件/文件夹后从底部出现，包含全选、下载、分享、移动、复制、删除。

### 9.3.1 上传队列（右下角）

开始上传后，页面右下角出现悬浮胶囊：显示整体进度与所有上传的总速度；点开是上传面板，可看每个文件的速度、进度与状态，也能取消/重试/更换文件续传。它属于整个站点，**切换页面不会中断上传**，刷新后仍可续传；收起面板不影响上传。

### 9.3.2 音频小窗（右上角）

双击音频文件后**默认只打开右上角小窗**（不会弹出大播放器），小窗覆盖完整播放控制：播放/暂停、拖进度、音量、上一首/下一首、播放模式（顺序 → 列表 → 单曲 → 随机）、播放列表与展开按钮。播放列表向下展开，每页 8 首、可翻页点歌；只有 1 首时上一首/下一首置灰。点小窗外部或小窗的 × 只会收起小窗，**音乐继续播放**；顶栏的音符图标可以随时把它叫回来。小窗右上角的「>」打开完整播放器（见 11.1）。

## 9.4 选择文件

| 操作 | 效果 |
|---|---|
| 单击文件或文件夹 | 选中（不会直接打开） |
| 双击文件夹 / 文件 | 进入目录 / 预览或播放 |
| Shift + 单击 | 选中以最后点击为锚点的连续区间（替换当前选择） |
| Ctrl（macOS 为 ⌘）+ 单击 | 加选 / 取消单项 |
| Ctrl + Shift + 单击 | 把区间并入当前选择 |
| 单击行首/卡片角上的复选框 | 切换该项（触屏同样可用） |
| 在空白处按住拖动 | 框选 |
| 列表头复选框 | 全选当前页 |
| Ctrl/Cmd + A | 全选当前列表（输入框、对话框、播放器中不生效） |

## 9.5 视图偏好

默认视图是**网格**；切换为「列表」后记在本机浏览器里，下次登录仍保持；不同账号之间互不影响。升级到本版后旧的列表偏好会被重置为网格一次。

## 9.6 手机与窄屏

窗口宽度小于约 860 像素时，左侧栏会隐藏。此时通过顶部栏的搜索框与账户菜单进入各页面；桌面端请用宽屏以获得完整导航。

## 9.7 快捷键与小技巧

- `空格`：把当前选中的文件加入下载队列（在输入框或对话框中不生效）。
- `Esc`：关闭对话框与顶部搜索。播放浮层用右上角按钮「收起」（音频继续播放）或「关闭并停止」。
- 双击文件或文件夹：打开（进入目录 / 播放或预览）。
- 把文件或文件夹拖到页面任意位置：直接上传到当前目录。
- 分组标题（如「我的文件」「组空间」）不可点击，只用于分区。

## 9.9 外观与主题

设置页「外观」提供 5 套主题色卡：日落（默认）、森林、海岸、极光、暗色，与右上角头像菜单里的主题列表是同一份偏好；选择会**保存到账号**，换设备登录后自动跟随。当前选中的主题色卡、侧栏当前页面会播放一次短暂扫光（进入页面后 1 秒一次、间隔 5 秒、20 秒后停止）；系统开启「减少动态效果」时不播放。

## 9.8 页面打不开时

- 刷新页面后仍在原页面（地址里带目录 id），说明地址可直接收藏。
- 若提示登录失效，会跳回登录页；重新登录即可。
- 权限相关页面（例如组空间）打不开时，通常是没有加入该组或链接已过期，见 17. 常见问题。

## 主题切换

右上角头像菜单里可以切换配色，内置 5 套：日落（默认）、森林、海岸、极光、暗色。登录后选择会**保存到账号**，换浏览器/设备登录同一账号会自动跟随；未登录页面（登录、注册、分享）仍用本机缓存。列表/网格视图同样按账号记忆。个人设置也从该菜单进入（侧栏不再重复放「设置」），同一菜单里还有「退出登录」。
