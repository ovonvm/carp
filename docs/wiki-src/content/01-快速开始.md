# 1. 快速开始

Carp 2.0 把「网页界面 + 文件服务 + 用户系统 + 后台任务」全部装进一个可执行文件，所以部署只有三步：拿到程序、准备数据目录、打开浏览器登录。

## 1.1 三种部署方式

| 方式 | 适合谁 | 怎么开始 | 默认数据目录 |
|---|---|---|---|
| Linux 安装包（推荐） | 服务器、NAS、长期运行 | 解包后执行 `sudo ./install.sh`，自动注册 systemd 服务 | `/opt/carp/data` |
| 便携运行 | 临时试用、没有 systemd 的环境 | `./carp serve`，前台运行 | 程序所在目录下的 `data/` |
| Windows 控制面板 | Windows 10/11 桌面 | 双击 `Carp.exe`，点「打开网盘」 | `Carp.exe` 同目录 |

三种方式运行的是同一个核心程序，功能完全一致，区别只在安装与服务管理方式。

## 1.2 Linux：安装包方式

```bash
tar -xzf carp-v2.2.1-linux-amd64.tar.gz
cd carp-v2.2.1-linux-amd64
sha256sum -c SHA256SUMS
sudo ./install.sh
```

安装脚本会：

1. 把程序放到 `/opt/carp/carp`，创建受限系统用户 `carp` 运行它；
2. 生成 `/opt/carp/carp.env`（配置文件）并注册 systemd 服务；
3. 启动服务并等待健康检查通过，最后打印「Carp 安装完成」信息框：服务地址、局域网 IP、管理员账号、**初始密码**（只显示这一次）、数据目录、配置文件、密码文件和本次服务状态；用 `--no-credentials` 安装时只隐藏密码本身。

之后执行：

```bash
carp doctor      # 自检，全绿即可
carp             # 打开运维菜单（启动/停止/备份/升级等）
```

运维菜单的状态行会显示访问地址；菜单里的 `1`/`2`/`3`（启动/停止/重启）会显示进度和结果，不再静默返回。

## 1.3 Windows：控制面板方式

1. 把 `Carp.exe` 放到一个单独文件夹（不要放在中文或很深的路径下，也不要放进 `Program Files`，否则数据目录不可写）。
2. 双击运行，**不需要管理员权限**；数据直接写在这个文件夹里。
3. 首次启动会自动创建管理员 `admin`，同时弹出「账号与密码」窗口显示初始密码（只显示一次），并保存在同目录的 `bootstrap\initial-admin.txt`。初始密码之后可在面板「高级 → 管理员账号」里再次查看。
4. 点面板上的「打开网盘」（或手动打开 <http://127.0.0.1:50011>）。
5. 用 `admin` 和初始密码登录，然后到「设置」修改密码。

面板左侧「设置」可以改端口、profile、日志级别、开机自启；「立即备份」把数据打包到你选的目录。关闭窗口会停止服务并退出核心。

## 1.4 便携方式（任意系统）

```bash
chmod +x carp
./carp serve
```

浏览器打开 `http://127.0.0.1:50011`。首次启动会打印 `admin` 的初始密码；`Ctrl+C` 优雅退出。数据默认写在程序旁边的 `data/` 目录。

## 1.5 第一次登录

1. 打开 `http://127.0.0.1:50011`。
2. 用户名填 `admin`，密码填安装/首次启动时显示的初始密码。
3. 登录后先到「设置 → 修改密码」改掉初始密码（改密后其它设备上的旧会话会失效）。

> 初始密码只显示一次（同一份也写在数据目录的 `bootstrap/initial-admin.txt`，改密后自动删除）。忘记时可以：Linux 用 `sudo carp reset-admin-password`；Windows 用面板快捷操作「重置 root 密码」。重置后需要重新登录。

## 1.6 安装后目录速览（Linux）

| 路径 | 内容 |
|---|---|
| `/opt/carp/carp` | 程序二进制 |
| `/opt/carp/carp.env` | 环境变量配置文件（权限 0600） |
| `/opt/carp/data/db/carp.db` | SQLite 数据库（WAL 模式） |
| `/opt/carp/data/storage/` | 文件内容（按内容哈希存放） |
| `/opt/carp/data/bootstrap/` | 首次管理员信息（改密后自动删除） |
| `/opt/carp/backup/` | 备份目录（由备份脚本生成） |

Windows 面板下对应位置是 `Carp.exe` 同目录的 `db\`、`storage\`、`bootstrap\`、`logs\`（面板「打开数据目录」可直接打开）；备份文件在你每次选择的目录里，面板配置在 `%APPDATA%\Carp\gui.json`。

## 1.7 接下来做什么

- 想让别人也能访问：先读「5. 反向代理与 HTTPS」，不要直接把端口暴露到公网。
- 想在多台设备同步文件：登录后直接上传，「我的文件」就是你的根目录。
- 需要给同事分权限：读「16. 管理后台」的组管理，或先给他们各建一个账号。
- 想定时备份：读「7. 升级、备份与迁移」。
