# 3. Windows 部署

Windows 版本是一个**单文件控制面板**：一个 `Carp.exe` 里同时打包了图形界面和网盘核心（Go 核心在首次启动时释放到同目录的 `core\`），不需要安装、不需要 .NET 运行时、不需要管理员权限。

## 3.1 系统要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 x64 |
| 权限 | 普通用户即可；数据写在 `Carp.exe` 同目录的 `data\`、配置日志在同目录的 `conf\` |
| 位置 | 建议单独建一个文件夹存放 `Carp.exe`，避免中文路径与 `Program Files`（该目录不可写） |
| 网络 | 默认只监听本机 `127.0.0.1:50011` |

程序是便携式布局：`Carp.exe` 旁边固定只有 `data\`、`conf\`、`core\` 三个文件夹，**整个文件夹拷走就等于搬家**。

## 3.2 第一次运行

1. 把 `Carp.exe` 放进单独文件夹，双击运行。
2. 首次启动会自动创建管理员账号 `admin`，并弹出「账号与密码」窗口显示初始密码（只显示一次）。
   - 同一密码也写在 `data\bootstrap\initial-admin.txt`；修改密码后该文件自动删除。
   - 关掉弹窗后仍可用快捷操作「启动 / 停止」旁边的日志确认，或用记事本打开上面这个文件。
3. 主界面状态卡自动变为「服务运行中」，显示 `127.0.0.1:50011` 与运行时长。
4. 点「打开网盘」用默认浏览器进入登录页（也可以手动打开 <http://127.0.0.1:50011>）。
5. 用 `admin` + 初始密码登录，然后到「设置 → 修改密码」。

## 3.3 控制面板有什么

| 位置 | 功能 | 说明 |
|---|---|---|
| 状态卡 | 查看服务状态 | 运行中显示地址与已运行时长；停止时显示「已停止」 |
| 状态卡 | 打开网盘 | 用默认浏览器打开 `http://127.0.0.1:50011` |
| 状态卡 | 启动 / 停止 | 停止会优雅关闭核心；启动会等核心就绪再显示运行中 |
| 快速操作 | 启动 / 停止 | 与状态卡同一动作，便于快速点 |
| 快速操作 | 打开数据目录 | 资源管理器打开 `data\` 目录 |
| 快速操作 | 运行自检 | 在面板下方输出 `carp doctor` 的检查结果 |
| 快速操作 | 重置 root 密码 | 二次确认后只重置 `root` 账号密码，并显示一次新密码 |
| 备份卡 | 立即备份 | 选择目标目录，把数据打成 zip；运行中会先做 SQLite 快照 |
| 备份卡 | 上次备份 | 显示上次备份时间与位置 |
| 运行日志 | 查看 / 清空 | 面板日志滚动显示，最近日志见 `conf\logs\gui-YYYYMMDD.log` |
| 左栏「设置」 | 服务与存储设置 | 端口、profile（low/high）、日志级别、cookie-secure、开机自启；数据目录只读展示 |
| 左栏「打开数据目录 / 打开日志文件」 | 快捷入口 | 资源管理器定位到目录或日志文件 |
| 左栏「关于」 | 版本信息 | GUI 版本、核心版本、核心路径、数据目录、配置文件路径 |

## 3.4 数据放在哪

| 路径（相对 `Carp.exe` 所在目录） | 内容 |
|---|---|
| `data\db\carp.db` | 数据库（SQLite，WAL 模式） |
| `data\storage\` | 文件内容（按内容哈希存放） |
| `data\bootstrap\initial-admin.txt` | 初始管理员信息（改密后删除） |
| `data\tmp\` | 上传/转换临时文件 |
| `conf\gui.json` | 面板配置（端口、profile、日志级别、自启、上次备份位置） |
| `conf\logs\gui-YYYYMMDD.log` | 面板日志，按天切分、保留 7 天 |
| `conf\backups\` | 「立即备份」没选目录时的默认输出位置 |
| `core\carp-core.exe` | 首次启动释放的服务核心（带 `.sha256` 校验文件） |

如果 `Carp.exe` 目录不可写（例如放进了 `Program Files`），面板会整棵树回退到 `%LOCALAPPDATA%\Carp`（下有同样结构的 `data\`、`conf\`、`core\`）并在日志里说明。

> **从旧版本升级注意**：旧面板把数据放在 `%ProgramData%\Carp\data`，本版本**不会自动迁移**，升级后是空数据。需要保留旧数据时，把旧 `%ProgramData%\Carp\data` 里的 `db\`、`storage\`、`bootstrap\` 原样拷贝到 `Carp.exe\data\`，再启动面板。

## 3.5 端口被占用怎么办

启动时如果 `50011` 被别的程序占用，面板会弹出提示，列出占用进程的 PID、进程名和可执行文件路径，并提供「结束进程」按钮（需要确认）。面板**不会自动换端口**——端口是与反向代理、书签、其它设备约定的契约，静默改掉更容易出问题。想换端口请到「设置」里改。

## 3.6 让局域网里的其它设备访问

面板固定监听 `127.0.0.1`，这是最安全的默认值。要让局域网访问：

1. 在本机放一个反向代理（Nginx / Caddy），把 `http://127.0.0.1:50011` 转发到局域网地址；
2. 或者直接用命令行核心监听 `0.0.0.0`（见 3.9），并自行在防火墙放行端口。

> 局域网明文访问意味着同网段的人可能看到传输内容。正式使用建议按「5. 反向代理与 HTTPS」配置 HTTPS。

## 3.7 升级

1. 面板点「停止」。
2. 用新的 `Carp.exe` 覆盖旧文件（`data\`、`conf\`、`core\` 都在同目录，不受影响）。
3. 重新双击运行，点「启动」。

面板每次启动会按内嵌核心的 SHA-256 校验 `core\carp-core.exe`，版本不同会自动重新释放，不需要手工删 `core\`。数据库迁移在核心启动时自动执行。

升级前建议先点「立即备份」做一次 zip 备份。

## 3.8 卸载

1. 面板点「停止」，关闭窗口（核心会一起退出）。
2. 删除 `Carp.exe` 所在文件夹 —— **这会删除所有数据**，需要保留请先备份。
3. 没有额外残留：面板配置与日志都在 `conf\` 里，随文件夹一起删掉。
4. 如果开过「开机自启」，面板保存设置时会同步删除/写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `Carp` 项。

## 3.9 只想用命令行核心

面板本质是给 `core\carp-core.exe` 套了一层界面。也可以直接运行核心：

```powershell
& ".\core\carp-core.exe" serve -data "D:\Carp\data" -addr 127.0.0.1:50011
```

`-data` 指向面板的数据目录即可共用同一份数据，但**不要与面板同时运行**（端口会冲突，面板启动时会检测到外部核心并询问是否接管）。
