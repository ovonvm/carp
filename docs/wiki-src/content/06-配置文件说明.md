# 6. 配置文件说明

Carp 没有 TOML/YAML/JSON 格式的「配置文件」。运行参数只有一个来源：**命令行参数 > 环境变量 > 内置默认值**。安装包在 Linux 上额外生成一个 `carp.env`，它本质上就是一组环境变量。

## 6.1 配置放在哪

| 平台 / 方式 | 配置位置 | 修改方式 |
|---|---|---|
| Linux 安装包 | `/opt/carp/carp.env`（0600，systemd 通过 EnvironmentFile 读取） | `sudo carp config` 或直接编辑，再 `sudo systemctl restart carp` |
| Linux 便携 | 无文件；启动参数 / 当前 shell 的环境变量 | `./carp serve -addr ... -data ...` 或 `export CARP_...` |
| Windows 控制面板 | `<Carp.exe 目录>\conf\gui.json`（端口、profile、日志级别、Cookie 安全、开机自启、上次备份位置） | 控制面板左栏「设置」修改后点「保存」 |

## 6.2 常用参数

| 参数（命令行 / 环境变量） | 默认 | 说明 |
|---|---|---|
| `-addr` / `CARP_ADDR` | `127.0.0.1:50011` | 监听地址；局域网访问改 `0.0.0.0:50011` |
| `-data` / `CARP_DATA_DIR` | 程序旁的 `data/`（安装包为 `/opt/carp/data`） | 数据库与文件所在目录 |
| `-log-level` / `CARP_LOG_LEVEL` | `info` | `debug`/`info`/`warn`/`error` |
| `-profile` / `CARP_PROFILE` | `low` | `low` 面向 512 MB 级机器；`high` 面向 4 GB+ |
| `-cookie-secure` / `CARP_COOKIE_SECURE` | `auto` | `auto` 按请求是否 HTTPS；HTTPS 反代建议 `always` |
| `-allow-origin` / `CARP_ALLOW_ORIGINS` | 空 | 额外允许的浏览器来源，可重复 |
| `-worker` / `CARP_WORKER` | `internal` | `external` 时后台任务改由独立的 `carp worker` 进程执行 |
| `-qb-url` / `CARP_QB_URL` | 空 | qBittorrent WebUI 地址；也可在管理后台「系统设置 → 离线下载」填写（此项一旦设置则后台只读） |
| `-qb-username` / `CARP_QB_USERNAME` | 空 | qBittorrent WebUI 用户名（同上） |
| `-qb-password` / `CARP_QB_PASSWORD` | 空 | qBittorrent WebUI 密码（同上；后台保存的密码会加密存放） |
| `-allow-private-downloads` / `CARP_ALLOW_PRIVATE_DOWNLOADS` | 关 | 允许离线下载访问私网地址（有 SSRF 风险，仅内网测试） |
| `-pprof` / `CARP_PPROF` | 关 | 在回环地址暴露 Go pprof，用于诊断 |

`-profile low` 与 `high` 的差别在于数据库连接数、缓存大小、缓存/上传并发等内部参数；普通机器保持默认 `low` 即可，`high` 适合内存充足、并发较大的主机。

## 6.3 carp.env 示例

```bash
CARP_ADDR=127.0.0.1:50011
CARP_DATA_DIR=/opt/carp/data
CARP_PROFILE=low
CARP_COOKIE_SECURE=auto

# 可选
#CARP_WORKER=external
#CARP_QB_URL=http://127.0.0.1:8080
#CARP_QB_USERNAME=admin
#CARP_QB_PASSWORD=change-me
```

查看当前生效的配置：

```bash
sudo carp config --show
```

交互式修改常用项（监听地址、数据目录、profile、cookie-secure）：

```bash
sudo carp config
sudo systemctl restart carp
```

## 6.4 哪些改动需要重启

| 改动 | 是否要重启 |
|---|---|
| 监听地址、端口、数据目录、profile、cookie-secure、worker、qB 连接 | 需要重启服务 |
| 站点设置（站点名、是否允许注册/注销、默认配额） | 保存即生效，不需要重启 |
| 存储策略（管理后台 → 存储） | 保存即生效 |

Linux 重启：`sudo systemctl restart carp`（`carp service restart` 会自动读取 `carp.env` 里的端口）；Windows：在控制面板「设置」里保存后，按日志提示停止再启动服务。

## 6.5 Windows 控制面板配置

`gui.json` 由控制面板维护，一般不需要手工编辑。它保存：监听端口、内存 profile（`low`/`high`）、日志级别、Cookie 安全策略、是否开机自启、上次备份位置。修改后点「保存」，面板会重启核心并做健康检查；端口改了之后浏览器地址也要跟着改。

数据目录不在 `gui.json` 里，它固定为 `Carp.exe` 同目录的 `data\`（exe 目录不可写时整棵树回退 `%LOCALAPPDATA%\Carp`），面板「设置」里只读展示。

## 6.6 命令行与服务的一致性

- 安装方式下，systemd 启动的是 `carp serve`，它会读取 `carp.env`；直接运行 `carp serve` 时**不读** `carp.env`，请用参数或当前 shell 的环境变量（避免同时启动两个实例争用数据库）。
- Windows 控制面板与命令行核心共用同一份数据目录（面板用 `Carp.exe\data`，命令行用 `-data` 指到同一个目录），不要同时运行两者；面板启动时若发现外部核心已在跑，会询问是否结束并接管。
